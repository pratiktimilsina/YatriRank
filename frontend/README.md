# YatriRank frontend

React + Vite UI for the YatriRank FastAPI backend. See the [project README](../README.md) for setup and for where
every displayed number comes from.

```
npm install
npm run dev
npm run lint
npm run build
```

Set `VITE_API_BASE_URL` in `frontend/.env` if the backend is not at http://localhost:8000.
